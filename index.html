01

在五度易链开放平台获取接口凭证

按订单类型选择对应的 APPID 和 KEY，作为服务端调用 API 的身份凭证。

API 凭证

登录五度易链 API 开放平台，在「数据中心 → 我的接口」查看已购买或已开通的接口权益。每个订单类型都有自己对应的 APPID 和 KEY，部署时请选择与接口权益匹配的一组。

  1. 打开 五度易链 API 开放平台
  2. 登录账号，进入「数据中心 → 我的接口」。
  3. 确认要使用的订单类型，并查看该订单对应的 APPID 与 KEY。
  4. 将凭证交给 MCP Server 服务端配置，不要放入 Skill、前端页面或 AI 对话框。
凭证不能混用

余额充值、接口套餐、包年套餐分别对应独立的 APPID 和 KEY。使用哪一类订单的接口权益，就必须配置哪一类订单对应的凭证。

订单类型 01余额充值APPID + KEY

使用余额账户中的接口调用额度，对应凭证仅用于该订单权益。

订单类型 02接口套餐APPID + KEY

使用接口套餐内的调用额度，需配置该套餐生成的凭证。

订单类型 03包年套餐APPID + KEY

使用包年套餐内的接口权益，不能与其他订单凭证交叉使用。

页面仅展示凭证位置和配置规则，不展示真实 KEY。API KEY 只保存在 MCP Server 服务端。
02

配置并部署业务型 MCP Server

按业务连接对应 Server，一个 Server 下会暴露该业务需要的 MCP Tool。

服务端配置

将 MCP Tool 作为 API 的包装层部署。Server 负责组织业务工具，工具内部继续复用五度易链原有接口、鉴权和计费体系。

  1. 根据业务选择一个 Server，确认需要暴露的工具集合。
  2. 在服务端写入对应订单的 APPID 和 KEY，并为客户端生成独立的 MCP 访问令牌。
  3. 将服务部署到公网 HTTPS 域名，确保豆包能够访问 Server 地址。
  4. 部署完成后先执行 initialize 和 tools/list，确认工具清单可发现。
三类凭证各司其职

API_APP_ID 与 API_SECRET（页面中的 KEY）只用于调用五度易链 API；MCP_AUTH_TOKEN 只用于客户端访问你部署的 MCP Server。

业务 Server企业尽调enterprise-diligence

企业主体、工商画像和尽调基础信息。

业务 Server风险与合规risk-compliance

司法诉讼、经营风险和合规核查。

业务 Server股权与关系equity-relations

股权结构、关系链路和控制关系。

业务 Server知识产权与经营ip-operations

知识产权、经营信息和企业能力。

服务端环境变量

把实际值写入部署环境或密钥管理服务。下面的 KEY 占位符对应「我的接口」中所选订单的 KEY。

API_APP_ID=订单对应的_APPID
API_SECRET=订单对应的_KEY
MCP_AUTH_TOKEN=客户端访问令牌
MCP_PUBLIC_URL=https://你的公网域名
03

在豆包或其他 AI 工具中连接

添加部署后的远程 Server，连接成功后由 AI 自动发现并调用 Tool。

客户端接入
豆包重点说明

在豆包的连接器或 MCP 设置中添加远程服务。具体入口名称会随客户端版本变化。

  1. 打开豆包，进入连接器 / MCP 服务设置。
  2. 选择添加远程 MCP 服务，填写部署后的 Server URL。
  3. 按豆包表单要求填写 MCP 访问令牌，通常使用 Bearer Token。
  4. 保存后检查工具列表，再发送验证问题。
通用远程 MCP 配置使用 MCP_TOKEN，不填 API KEY

安全边界

五度易链 API 的 APPID + KEY 只进入服务端；豆包等 AI 客户端只接收 MCP Server 地址和 MCP 访问令牌。不要把 API KEY 直接粘贴到客户端连接器或对话框中。

常见问题

接入过程中遇到问题时，可以先检查以下几项。

在哪里获取 APPID 和 KEY？

登录五度易链 API 开放平台，进入「数据中心 → 我的接口」，在对应订单类型下查看。余额充值、接口套餐、包年套餐分别使用各自对应的凭证。

为什么提示凭证无效或没有调用额度？

先确认服务端配置的 APPID 和 KEY 是否来自当前使用的订单类型，并检查该订单是否已开通对应接口权益。三类订单的凭证不能交叉使用。

豆包里应该填写哪一个 KEY？

客户端连接器填写部署后的 MCP Server 地址和 MCP 访问令牌，不填写五度易链 API 的 KEY。五度易链 API KEY 只在服务端用于调用原接口。

连接成功但看不到工具怎么办？

检查 Server 公网 HTTPS 地址、鉴权令牌和路由是否正确，然后重新执行 initialize 和 tools/list，确认对应业务 Server 的工具清单能够返回。
