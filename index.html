凭据和计费始终归属你自己，这是我们对外服务的底线。

计费按你的账号归属

每一次数据调用都通过你自己的开放平台账号完成鉴权与计费，用多少算多少，调用明细随时可在平台查看。

登录五度易链 API 开放平台，在「个人中心 → 我的接口」查看已购买或已开通的接口权益。每个订单类型都有自己对应的 APPID 和 SECRET，接入时请选择与接口权益匹配的一组。

  1. 打开 五度易链 API 开放平台
  2. 登录账号，进入「个人中心 → 我的接口」。
  3. 确认要使用的订单类型，并查看该订单对应的 APPID 与 SECRET。

常见问题与故障排查
接入过程中遇到问题时，可以先检查以下几项。
提示「凭据未配置」或 GATEWAY_NO_CREDENTIAL
客户端中没有填入 APPID 和 SECRET。按第 02 步在配置中补全凭据，保存后重试。
GATEWAY_CODE_401「该用户当前接口不可用」
该 APPID 未开通对应接口权限。联系平台客服开通权限，并核对调用参数是否正确。
GATEWAY_HTTP_401 / 403
APPID / SECRET 错误或账号无权限。核对凭据是否来自当前使用的订单类型——余额充值、接口套餐、包年套餐的凭据不能交叉使用。
GATEWAY_HTTP_429
触发网关限流。稍后重试，或降低调用频率。
连接成功但看不到工具怎么办？
检查端点地址拼写与网络连通性，确认凭据已填写。服务端为无状态设计，无需本地部署；若仍异常，重新保存配置后再试。
AI 没有使用 MCP 回答怎么办？
配置已保存但 AI 仍直接回答、没有调用 MCP 工具时，请打开一个新的会话窗口重新提问；如果仍未生效，重启平台后再试。
在哪里获取 APPID 和 SECRET？
登录五度易链 API 开放平台，进入「个人中心 → 我的接口」，在对应订单类型下查看。
填入页面的凭据安全吗？
凭据只在你本页面的浏览器里临时替换到配置代码中，不会上传或保存；复制后请粘贴到自己的客户端配置里，不要发给他人。
